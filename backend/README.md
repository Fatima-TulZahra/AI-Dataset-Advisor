# Backend

This directory contains the Python backend modules for the AI Dataset Advisor project.

## Modules

- Dataset Analysis: Analyze dataset structure and statistics.
- Data Quality Analysis: Detect missing values, duplicates, and potential outliers.
- Data Cleaning: Recommend and apply data-cleaning operations.
- Feature Engineering: Prepare features for machine learning.
- ML Recommendation: Recommend suitable machine learning algorithms.
- Model Evaluation: Train, evaluate, and compare candidate models.
- Meta-Learning: Learn algorithm recommendations from previous experiments.

## Technologies

- Python
- Pandas
- NumPy
- Scikit-learn
- SciPy

## Development

The backend will initially be developed and tested in Google Colab.
Reusable Python modules will be organized in this directory as development progresses.

FastAPI will be integrated later to connect the backend with the React frontend.
